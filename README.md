# RideMetrics – Ojol Earnings & Performance Analytics

RideMetrics is a web-based analytics platform designed to help Indonesian online motorcycle taxi (ojol) drivers track, analyze, and optimize their earnings, operational expenses, and working productivity.

The platform provides an integrated dashboard for monitoring financial performance, tracking daily transactions, analyzing working patterns, and understanding actual net income. By transforming everyday operational data into meaningful insights, RideMetrics helps drivers make more informed decisions about their working schedules and financial goals.

Key features include earnings and expense management, interactive performance dashboards, working-hour analytics, income forecasting using machine learning, and AI-powered insights.

Built with Python, FastAPI, React, TypeScript, PostgreSQL, and Scikit-learn, RideMetrics aims to combine modern full-stack software engineering with practical data analytics and machine learning to address a real-world problem faced by gig economy workers.

**The ultimate goal is to turn everyday driving data into actionable insights that help drivers work smarter and manage their finances more effectively.**
